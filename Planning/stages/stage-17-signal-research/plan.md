**Goal:** before any agent or pod trusts a signal, measure whether it predicts returns: forward-return labels that can never leak into features, information coefficients (Pearson and Spearman, Newey-West t, IR, hit rate, by sector and by regime), quintile analysis (mean return per bucket, monotonicity, long-short spread, cumulative spread), decay (IC across horizons, rank autocorrelation) and a vectorised long-short backtest with costs, packaged as a `SignalTearSheet` (JSON + matplotlib figures) and a CLI. Consumers: Stage 22 (systematic alpha models: which features/factors to combine), Stage 23 (stat-arb signals), Stage 34 (quant analyst agent), Stage 21 plugs regimes into the by-regime IC.

**Architecture:** `atlas.quant.research`:
- `labels.py` — `compound_forward` (pure), `ForwardReturns` (realised daily returns + one label frame per horizon, all tagged as labels), `forward_returns(view_factory, dates, symbols, horizons)` (one `DataView` after the last label session).
- `signals.py` — `evaluation_dates(start, end, frequency)`, `signal_kind(name)`, `SignalPanel`, `signal_panel(name, view_factory, dates)` (one point-in-time view per date; technical features via Stage 15 `compute_features`, fundamental factors via Stage 16 `factor_panel`).
- `ic.py` — `ic_series`, `newey_west_tstat`, `nw_lags`, `ICSummary`/`summarize_ic`, `ic_by_group` (sector), `ic_by_regime`, `ic_decay`, `rank_autocorrelation`.
- `quantiles.py` — `quantile_buckets`, `quantile_returns`, `monotonicity`, `daily_quantile_returns`, `QuantileAnalysis`/`quantile_analysis`.
- `vector_backtest.py` — `long_short_weights`, `rebalance_dates`, `BacktestResult`, `vector_backtest`.
- `tearsheet.py` — `SignalTearSheet` (`.summary` dict, `.figures`, `.save(dir)`), `build_tearsheet` (pure), `research_signal` (reads data, builds the sheet).
- `atlas.cli.research_cmd` — `atlas research signal --name … --from … --to …`.
- Look-ahead guard for labels in `atlas.core.pit` (`tag_label`, `is_label`, `guard_not_label`), used by every research entry point that takes a signal and by Stage 16's `composite`.

**Tech stack:** pandas 3 / numpy (ranks, Newey-West written out; no scipy/statsmodels), Pydantic v2 config, **matplotlib** (new runtime dependency, Agg backend) for the figures, Typer + Rich for the CLI.

## Collisions with the overall plan
None with the roadmap (row 17, depends on 15 and 16; Phase 2 / M2) or the spec (§3 principles 2 (DataView only) and 6 (no guess: NaN), §11 numerics, §12 `quant/ … research`, §15 A7). Interpretations and deviations, also logged in `PROGRESS.md › Decisions log`:

1. **Timing convention (t → t+h).** A signal dated on decision day `t` is what a `DataView` at `t` (08:00 New York, `calendar.decision_time`) computes, so it uses bars up to the close of `t−1`. Its label for horizon `h` is the total return from the close of `t` to the close of the session `h` sessions later: `label_h(t) = Π_{k=1..h} (1 + r_{t+k}) − 1` with `r_s` the simple daily total return of session `s` (adjusted close). The backtest uses the same convention: positions decided on `t` trade at the close of `t` and earn from `t+1` on. The night and day of `t` are skipped (a one-session implementation lag, conservative: never a return the signal could not have traded).
2. **`forward_returns` signature.** The brief's `forward_returns(view_factory, horizons=[1,5,21,63])` cannot know which dates and names to label, so it takes them too: `forward_returns(view_factory, dates, symbols, horizons=None)` (`horizons` default `quant.research.horizons`). `view_factory(day) -> DataView`. Labels are read through **one** view at the session after the last label session (the first decision moment at which every label is realised), from `DataView.returns` (adjusted with the actions known then). A missing bar anywhere in a label's window gives NaN (no guess); a label whose window ends after the lake's last bar is NaN (not realised). Names that delist drop out of the labels of the windows they do not finish (a known, documented bias; the full backtester in Stage 56 handles delisting cash-outs).
3. **Label guard.** Labels exist for evaluation only. Every label frame carries a pandas `attrs` tag (`atlas_label`), which pandas propagates through arithmetic, ranks, shifts, reindexing and slicing; `ForwardReturns` is not a DataFrame. `atlas.core.pit.guard_not_label(obj, what)` raises `LookAheadError` for a tagged frame/series or a `ForwardReturns`. It runs on every signal argument of the toolkit (`ic_series`, `quantile_buckets`, `rank_autocorrelation`, `vector_backtest`, `build_tearsheet`, `signal_panel`'s output check) and in Stage 16's `composite` (an earlier-stage change: one guard call). It catches accidental use; deliberately stripping the tag (`DataFrame(frame.to_numpy())`) is not prevented and is documented as such. The guard lives in `atlas.core.pit` (not in `research`) so that `quant.factors` can use it without a circular import.
4. **Evaluation dates.** Signals are evaluated on decision days: the first session of each period of `quant.research.frequency` (`daily`, `weekly`, `monthly`; default `monthly`). One point-in-time view per date costs ~16 s on the real lake (measured: the day's quality report dominates; the first view ~70 s), so daily evaluation of 2016–2021 (~1,500 views) is impractical from the CLI; monthly takes ~20 min.
5. **Signal panel (sixth file `signals.py`).** The brief lists five module files; building the point-in-time signal panel the CLI needs (which names, which dates, which library) gets its own file, like Stage 16's `store.py`. A name is a Stage 15 technical feature (`REGISTRY`) or a Stage 16 fundamental factor (`FACTOR_NAMES`; its cleaned z-score exposure); anything else raises `ValueError`. For each date: the members of `quant.research.universe` at that date (point-in-time membership, so later index leavers are included: no survivorship bias), the signal from a view at that date. Sectors (today's, Stage 08 limitation) come from `DataView.instrument`; a name without a sector or instrument row has sector `None`.
6. **IC.** Per date, over the names with both a signal and a label: Pearson correlation, and Spearman = Pearson of average ranks. Fewer than `quant.research.min_names` such names → NaN for that date (dropped from summaries). Summary: mean, std (ddof 1), IR = mean / std (per evaluation period, not annualised), Newey-West t-stat of the mean (Bartlett weights, lags `L = max(ceil(h / step) − 1, 0)` where `step` = median sessions between evaluation dates, so overlapping windows are accounted for), hit rate = share of dates with IC > 0, number of dates.
7. **IC by sector / by regime.** By sector: each sector's own cross-section per date (needs `quant.research.min_group_names` names). **Names without a sector are not grouped together** (in the real lake every former S&P 500 member has no sector, so such a group would be the future index leavers: the Stage 16 audit lesson); they are left out of the by-sector table and counted. By regime: an optional `regimes` series (date → label) groups the IC series; Stage 21 supplies regimes, until then the tear sheet reports "not available".
8. **Quantiles.** Per date, `quant.research.n_quantiles` (5) buckets from average ranks: `bucket = floor((rank − 1) · q / n) + 1` (equal sizes up to one name; ties share a bucket, so a constant signal puts every name in one bucket and has no spread). Mean label per bucket per date, averaged over dates; monotonicity = Spearman correlation between bucket number and mean return (+1 increasing, −1 decreasing); spread = top − bottom per date (mean and Newey-West t); cumulative spread chart data = daily: bucket membership held from each date to the next, equal-weight daily bucket returns, `Π(1 + top − bottom) − 1`.
9. **Decay.** Mean IC per horizon (Pearson and Spearman); rank autocorrelation of the signal at lags of `quant.research.autocorr_lags` evaluation dates (mean over dates of the Spearman correlation of `signal_t` and `signal_{t−k}` over names present at both); turnover proxy = 1 − lag-1 autocorrelation.
10. **Vectorised L/S backtest.** On each rebalance date (the first evaluation date of each `quant.research.backtest.rebalance` period: `signal`, `weekly`, `monthly`, `quarterly`) long the top bucket and short the bottom bucket, each leg `gross / 2` of NAV (default gross 2.0: 100/100, so the equal-weight backtest tracks the quintile spread), equal weights or signal weights ∝ |average-rank pct − 0.5|. Trades at the close of the rebalance date; weights drift with returns between rebalances (`w ← w(1+r)/(1+R)`); a missing daily return counts as 0 (position held at its last price; documented). Turnover per rebalance = Σ|w_target − w_drifted| (the first one = gross); cost = turnover × `cost_bps` / 10⁴, charged on the rebalance session. Daily net returns; summary: annualised return (mean × P), annualised vol (std × √P), Sharpe = mean/std × √P (rf 0, P = `quant.features.sessions_per_year`), max drawdown, mean turnover per rebalance, annual turnover, total cost, number of rebalances. Either leg empty → flat (no trade).
11. **Tear sheet.** `SignalTearSheet`: `summary` (JSON-able dict: meta, IC per horizon and method, decay, quantiles, by-sector, by-regime, backtest), the series behind the charts, and matplotlib figures (`ic.png` IC per date + rolling mean, `quantiles.png` mean return per bucket per horizon, `cumulative_spread.png`, `decay.png` IC by horizon + rank autocorrelation, `backtest.png` cumulative net return). `save(out_dir)` writes `tearsheet.json`, the PNGs and CSVs (`ic_series.csv`, `quantile_returns.csv`, `backtest_returns.csv`). Default directory `<lake>/runs/research/<name>/` (the brief's `data/runs/research/<name>/`; `data/` is the lake), configurable with `--out`.
12. **New dependency.** The brief requires matplotlib figures; matplotlib is not in the spec §11 list (which does not exclude it) and not yet installed: added to `[project].dependencies` (the CLI needs it at runtime), floor = the version installed.
13. **CLI.** `atlas research signal --name N --from F --to T [--frequency] [--universe] [--out]`; `--from 2016` means 2016-01-01 and `--to 2021` means 2021-12-31 (a full date is also accepted). Reads the lake only; writes only the tear-sheet directory. Exit codes 0 ok, 1 the run failed (an `AtlasError`), 2 bad arguments. Prints a summary table.

## Design decisions

- **D1 Config** `cfg.quant.research` (`ResearchConfig`): `universe` sp500 · `horizons` (1, 5, 21, 63) sessions (positive, unique, ascending) · `frequency` monthly (`daily`/`weekly`/`monthly`) · `n_quantiles` 5 (≥ 2) · `min_names` 20 (≥ `n_quantiles`) · `min_group_names` 10 (≥ 3) · `autocorr_lags` (1, 2, 3, 6, 12) evaluation dates (positive, unique, ascending) · `rolling_ic_window` 12 dates (≥ 1) · `out_dir` `runs/research` (relative to the lake) · `backtest`: `rebalance` monthly (`signal`/`weekly`/`monthly`/`quarterly`), `weighting` equal (`equal`/`signal`), `cost_bps` 5.0 (≥ 0; per unit of one-side turnover, like `backtest.costs.half_spread_bps`), `gross` 2.0 (> 0). YAML block in `config/fund.yaml`, a comment per key.
- **D2 Label guard** in `atlas.core.pit`: `LABEL_ATTR = "atlas_label"`, `tag_label(frame) -> frame` (sets the attr on a copy), `is_label(obj) -> bool` (tagged frame/series, or an object with `__atlas_label__ = True`), `guard_not_label(obj, what="signal")` → `LookAheadError("… is a forward-return label …")`.
- **D3 Labels.** `compound_forward(daily, dates, horizon) -> DataFrame` (pure; `daily` index = session grid that contains every date; NaN when any return in the window is NaN or the window passes the grid's end). `ForwardReturns` (frozen dataclass, `__atlas_label__ = True`): `dates`, `horizons`, `daily` (tagged), `known_at` (the label view's `AsOf`), `horizon(h)` (tagged frame; unknown `h` → `ValueError`), `symbols`. `forward_returns(view_factory, dates, symbols, horizons=None, *, config=None)`: dates must be sessions, ascending, unique; one view at `next_session(offset(max date, max h))`.
- **D4 Signals.** `evaluation_dates(start, end, frequency, calendar=None)`; `signal_kind(name) -> "technical" | "fundamental"`; `SignalPanel` (frozen: `name`, `kind`, `values` (dates × symbols, NaN where not a member), `members` (date → tuple), `sectors` (symbol → sector or None)); `signal_panel(name, view_factory, dates, *, universe=None, progress=None)`.
- **D5 IC API.** `ic_series(signal, labels, *, method="spearman", min_names=None, config=None) -> Series`; `newey_west_tstat(series, lags) -> float`; `nw_lags(horizon, dates) -> int`; `ICSummary` (frozen: `mean, std, ir, t_stat, lags, hit_rate, n_dates`; `to_dict()`); `summarize_ic(series, lags)`; `ic_by_group(signal, labels, groups, *, lags, method, min_names) -> DataFrame` (one row per group: the summary fields + `names`); `ic_by_regime(series, regimes, *, lags) -> DataFrame`; `ic_decay(signal, labels, *, method) -> Series` (horizon → mean IC); `rank_autocorrelation(signal, lags) -> Series`.
- **D6 Quantiles API.** `quantile_buckets(signal, n_quantiles, *, min_names) -> DataFrame` (float 1..q, NaN outside); `quantile_returns(buckets, labels) -> DataFrame` (date × bucket mean); `monotonicity(means) -> float`; `daily_quantile_returns(buckets, daily) -> DataFrame` (session × bucket); `QuantileAnalysis` (frozen: `by_date`, `mean`, `spread`, `spread_mean`, `spread_t`, `monotonicity`, `cumulative_spread`); `quantile_analysis(signal, labels, horizon, *, config=None)`.
- **D7 Backtest API.** `rebalance_dates(dates, rebalance) -> tuple`; `long_short_weights(signal_row, *, n_quantiles, weighting, gross, min_names) -> Series`; `BacktestResult` (frozen: `returns` (net), `gross_returns`, `costs`, `turnover` (per rebalance), `weights` (rebalance × symbols), `summary` dict); `vector_backtest(signal, daily, *, config=None, rebalance=None, weighting=None, cost_bps=None, gross=None)`.
- **D8 Tear sheet + CLI.** `build_tearsheet(name, signal, labels, *, sectors=None, regimes=None, config=None) -> SignalTearSheet`; `research_signal(name, view_factory, start, end, *, config=None, frequency=None, universe=None, progress=None)`; `SignalTearSheet.save(out_dir) -> tuple[Path, ...]`. `atlas.cli.research_cmd.research_app` added to `atlas.cli.app` as `research`.
