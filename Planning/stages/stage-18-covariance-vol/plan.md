**Goal:** well-conditioned covariance matrices and next-session volatility forecasts from a frame of daily returns, for Stage 19 (factor risk model: specific risk, factor covariance), Stage 20 (VaR / risk metrics), Stage 42 (optimiser) and Stage 43 (vol-target sizing). Every covariance that leaves this package is symmetric, positive definite and has a bounded condition number.

**Architecture:** new package `atlas.quant.risk_model`:
- `psd.py` — `is_psd`, `condition_number`, `nearest_psd` (Higham 1988 eigenvalue clipping; `keep_diagonal=True` → Higham 2002 nearest correlation, rescaled), `nearest_correlation` (Higham 2002 alternating projections with Dykstra's correction), `floor_condition` (eigenvalue floor at λmax / κ).
- `covariance.py` — `CovResult`, `CovarianceEstimator` (base class: input checks, minimum-history policy, missing-data policy, PSD repair, condition check), `SampleCovariance`, `EWMACovariance`, `LedoitWolfCovariance` (constant-correlation target), `OASCovariance`, `covariance_estimator(method)` factory, `corr_from_cov`, `cov_from_corr`.
- `volatility.py` — annualisation helpers (`annualise_vol`, `annualise_variance`, `deannualise_vol`), `ewma_lambda`, `ewma_variance_path`, `VolForecast`, `ewma_vol`, `realised_vol`, `garch_vol` (GARCH(1,1) via `arch`, EWMA fallback), `blend_vol`, `forecast_vol`, `forecast_vols`.

**Tech stack:** numpy / pandas (all estimators and the PSD algorithms written out; no scikit-learn), **arch** (new runtime dependency, brings scipy and statsmodels; both are in spec §11), Pydantic v2 config.

Interpretations and design choices, also logged in `PROGRESS.md › Decisions log`:

1. **Units.** Input: simple daily returns (fractions), a `DatetimeIndex` (or date index) strictly ascending, one float column per name. Every output is **daily**: `cov` in return² per session, `vol` the daily standard deviation. Annualisation is explicit through the helpers, with `P = quant.features.sessions_per_year` (252; the key Stage 17 also used for Sharpe), not a second config key.
2. **Mean.** Sample, Ledoit-Wolf and OAS demean each column; EWMA and the vol forecasts assume a zero daily mean (RiskMetrics; the daily mean is two orders of magnitude below the daily vol). The sample estimator divides by `n − 1`; Ledoit-Wolf and OAS divide by `n`, as in their papers (the shrinkage formulas are derived for that `S`).
3. **EWMA.** Weight of the return `k` sessions before the last row is `λ^k`, normalised so the weights sum to 1 (finite-history RiskMetrics; a constant variance is estimated without bias). `λ` from `quant.risk_model.ewma_lambda` (0.94, RiskMetrics daily) or from a half-life `h` sessions: `λ = 0.5^(1/h)` (the estimator takes one or the other, not both). Weights follow row positions, so a missing return keeps its decay slot but adds nothing.
4. **Ledoit-Wolf** = Ledoit & Wolf (2004), "Honey, I shrunk the sample covariance matrix": target `F` with the sample variances and the average sample correlation `r̄`; intensity `δ = max(0, min(1, (π̂ − ρ̂) / γ̂ / T))` with `π̂`, `ρ̂`, `γ̂` as in the paper (the published `covCor.m`). **OAS** = Chen, Wiesel, Eldar & Hero (2010), eq. (23): target `tr(S)/N · I`, `ρ̂ = min(1, ((1 − 2/N) tr(S²) + tr²(S)) / ((T + 1 − 2/N)(tr(S²) − tr²(S)/N)))`. Both are written out in numpy; a loop-based literal implementation in the tests cross-checks Ledoit-Wolf.
5. **Missing data and minimum history.** Policy `quant.risk_model.missing`: `pairwise` (default; every pair uses the sessions where both names have a return, then the matrix is repaired to the nearest PSD matrix with the variances kept) or `complete` (only sessions where every kept name has a return). Minimum history `quant.risk_model.min_history` (63 sessions): a name with fewer returns is dropped; under `pairwise`, while some pair shares fewer than `min_history` sessions the name in most such pairs is dropped (ties: fewer returns, then the later name in sort order); a constant name (zero variance) is dropped. Dropped names are reported with the reason (`history`, `overlap`, `constant`) in `CovResult.dropped` and never estimated (spec §3.6: no estimate, no new risk, never a guess). No name left, or fewer than `min_history` complete sessions under `complete` → `DataError`. The pairwise sample covariance equals pandas' `DataFrame.cov()` (means over each pair's common sessions). For Ledoit-Wolf/OAS under `pairwise`, the moments are averaged over each pair's common sessions and `T` is the mean pair count (exact for complete data; an approximation otherwise, documented).
6. **PSD repair and condition check.** After estimation, the matrix is symmetrised; if its smallest eigenvalue is below `−1e-12 · λmax` it is replaced by `nearest_psd(…, keep_diagonal=True)` (Higham 2002 on the correlation matrix, rescaled by the vols, so variances are kept); then, if `λmax / λmin > quant.risk_model.max_condition` (1e5), eigenvalues are floored at `λmax / max_condition`. Each step is recorded in `CovResult.adjustments` (`"nearest_psd"`, `"condition_floor"`) and logged as a warning. So every output is positive definite with condition number ≤ `max_condition` (up to rounding).
7. **`nearest_psd(matrix)`** (Higham): default = Higham (1988), the nearest symmetric PSD matrix in Frobenius norm (symmetric part, eigenvalues clipped at 0). `keep_diagonal=True`: scale to a correlation matrix, `nearest_correlation` (Higham 2002), scale back. `nearest_correlation` returns the PSD projection of the last iterate rescaled to a unit diagonal (a congruence, so the output is exactly PSD with an exact unit diagonal); not converged within `max_iter` → still PSD, warning logged.
8. **`CovResult`** is a frozen dataclass (as Stage 17's `ForwardReturns`): `symbols`, `method`, `n_obs` (sessions used), `shrinkage` (`None` for sample/EWMA), `condition_number`, `adjustments`, `dropped` (read-only mapping name → reason), `end` (last session). `cov`, `corr` (DataFrames) and `vol` (Series) are properties built from read-only arrays, so a caller that edits them cannot change the result (the Stage 17 audit F lesson).
9. **Vol forecasts** (one name, next session, daily): `ewma` (as 3, zero mean), `realised` (root mean square of the last `realised_window` returns, zero mean, NaN skipped), `garch` (GARCH(1,1), zero mean, normal errors, fitted by `arch` on returns in percent; the one-step forecast `ω + α r_T² + β σ_T²`), `blend` (variance-weighted `w_ewma σ²_ewma + w_garch σ²_garch + w_realised σ²_realised`, weights in config, summing to 1). GARCH **falls back to EWMA** (recorded in `VolForecast.fallback` with the reason, warning logged) when: fewer than `garch_min_obs` returns, the optimiser raises, `convergence_flag ≠ 0`, or the fitted parameters are invalid (`ω ≤ 0`, `α < 0`, `β < 0`, `α + β ≥ 1`). A series with fewer than `min_history` returns → `DataError` (no forecast). NaN returns are dropped before the GARCH fit (`arch` takes no NaN).
10. **No CLI and no long-running entry point** in this stage (the brief lists none): nothing to wrap in a `run_context`; warnings go through `get_logger` and carry the `run_id` when a caller's `run_context` is open. A `covariance_from_view` convenience (DataView → returns → estimate) is left to the consumer stages (Backlog).

## Design decisions

- **D1 Config** `cfg.quant.risk_model` (`RiskModelConfig`): `min_history` 63 (≥ 2) · `missing` `pairwise` (`pairwise`/`complete`) · `max_condition` 1e5 (> 1) · `default_method` `ledoit_wolf` (`sample`/`ewma`/`ledoit_wolf`/`oas`) · `ewma_lambda` 0.94 (0 < λ < 1) · `volatility` (`VolatilityConfig`): `method` `blend` (`ewma`/`garch`/`realised`/`blend`), `realised_window` 21 (≥ 2), `garch_min_obs` 252 (≥ 30), `blend_weights` (`BlendWeights`: `ewma` 0.4, `garch` 0.4, `realised` 0.2; each ≥ 0, sum 1 within 1e-9). YAML block in `config/fund.yaml`, a comment per key.
- **D2 PSD API** (`psd.py`): `is_psd(matrix, *, tol=1e-12) -> bool`; `condition_number(matrix) -> float` (`inf` when λmin ≤ 0); `nearest_psd(matrix, *, keep_diagonal=False, max_iter=200, tol=1e-9) -> ndarray`; `nearest_correlation(matrix, *, max_iter=200, tol=1e-9) -> ndarray`; `floor_condition(matrix, max_condition) -> ndarray`. Inputs: square, finite (`ValueError` otherwise); DataFrames keep labels.
- **D3 Covariance API** (`covariance.py`): `CovResult` (D-8 above); `CovarianceEstimator(*, config=None, min_history=None, missing=None, max_condition=None)` with `method: ClassVar[str]` and `estimate(returns: DataFrame) -> CovResult`; subclasses `SampleCovariance`, `EWMACovariance(lam=None, half_life=None, …)`, `LedoitWolfCovariance`, `OASCovariance`; `covariance_estimator(method=None, *, config=None, **kwargs)`; `corr_from_cov(cov)`, `cov_from_corr(corr, vol)`; `METHODS`.
- **D4 Volatility API** (`volatility.py`): `annualise_vol(x, periods=None, *, config=None)`, `annualise_variance(…)`, `deannualise_vol(…)` (float, ndarray, Series or DataFrame); `ewma_lambda(lam=None, half_life=None, *, config=None) -> float`; `ewma_variance_path(returns: Series, lam) -> Series` (value at `t` = forecast for the session after `t`, from returns up to `t`); `VolForecast` (frozen: `variance`, `vol`, `method`, `n_obs`, `params`, `fallback`, `annual_vol(periods)`); `ewma_vol`, `realised_vol`, `garch_vol`, `blend_vol`, `forecast_vol(returns, method=None, *, config=None)`, `forecast_vols(frame, method=None, *, config=None) -> dict[str, VolForecast]`.
- **D5 Errors.** Bad input (not a DataFrame/Series, non-numeric, ±inf, unsorted or duplicate index, empty) → `ValueError`; not enough data (history policy leaves nothing) → `atlas.core.errors.DataError`.
